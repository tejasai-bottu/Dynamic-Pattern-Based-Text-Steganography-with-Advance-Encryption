UNICODE STEGANOGRAPHY V2 — MANUAL COMPATIBILITY TEST FILE
========================================================================

HOW TO USE THIS FILE
  1. Open this file in UTF-8 aware editor (VS Code, Notepad++, etc.)
  2. Copy each test string (the part inside | | markers)
  3. Paste into target environment: browser, clipboard, OS text field,
     Word, Excel, Slack, WhatsApp, email, etc.
  4. Copy it back and paste into a char-count tool OR run:
       python unicode_compat.py verify '<pasted text>'
  5. Expected char count is shown after each test string.

  A result of 2 chars instead of 3 means the char was STRIPPED.
  A different char appearing means the char was CHANGED.
